# Х-28: источники США, Европы и международной платёжной отрасли

Проверено **17.10.2026**. Найдены основания считать доступный незаблокированный сеанс без присмотра риском несанкционированного доступа. Внутреннее правило ForteBank для кассира по-прежнему не установлено. Иностранные документы используются для обоснования модели риска и предложения правила проверки.

## Как использовать в кейсе

Предлагаемая формулировка: **«Рабочее место оставлено без присмотра при подтверждённо доступном незаблокированном сеансе: возможен несанкционированный доступ»**. Основание — сопоставимая практика безопасности; статус — сигнал для проверки человеком.

Для такого сигнала нужны наблюдаемые признаки отсутствия контроля и доступности сеанса. Светящийся монитор, открытое окно или отсутствие видимого нажатия Win+L сами по себе не доказывают, что сеанс остался доступен. Следует проверить блокировку по датчику присутствия, передачу контроля уполномоченному сотруднику и назначение экрана. Скрытые настройки нельзя достоверно восстановить по общему ракурсу камеры.

Для заключения о нарушении обязанности конкретного кассира дополнительно нужны действовавшая внутренняя инструкция ForteBank, её адресат, дата события и установленное состояние системы. Существующие государственные и банковские ссылки находятся в [каталоге правил](../rulebook.md) и [предварительной таблице сопоставления](../video_coverage.md). Порядок работы с таблицей в приватном репозитории команды описан в [PUBLISHING.md](../PUBLISHING.md).
