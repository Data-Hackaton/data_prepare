# Нормативный пакет в data_prepare

Снимок подготовлен 17.10.2026. Все 80 тем исходного каталога развёрнуты в процедуры; полнота этой структуры не означает полноту всего законодательства, 80 готовых видеодетекторов или подтверждённые нарушения.

## Состав

- `sources/`, `parsed/`, `source_manifest.json` — оригиналы и извлечение 17 официальных HTML-источников «Әділет» с контрольными суммами.
- `../parsed_documents/`, `../sources/` — прежняя выгрузка 10 актов, включая 4 дополнительных исторических документа/поправки. С учётом пересечения получается 21 государственный документ/версия. Исторические тексты не считаются действующими запретами.
- `forte_public/` — 31 публичный PDF ForteBank, извлечённые страницы, 14 карточек положений, оценка применимости и перечень недостающих внутренних документов.
- `comparative_security/` — официальные сравнительные материалы США, Европы и международной платёжной отрасли с областью применения. Они не заменяют норму РК или внутреннее правило ForteBank.
- `labor_safety/` — трудовое законодательство, охрана труда и электробезопасность: 5 актов и 14 тем в составе общего каталога 80 тем.
- `reference_workflows/` — 80 тематических процедур, 8 общих маршрутов, JSON/Markdown/CSV и проверка.
- `../rule_catalog.json` — исходный каталог 22 нормативных тем, используемый при пересборке общего каталога.

PNG в `verified_pages/` — изображения страниц публичных нормативных документов. Видеокадры и видео в этот нормативный пакет не добавляются. `video_coverage.json/.csv/.md` — сохранённая предварительная таблица сопоставления 42 файлов с нормами; она предназначена для приватного репозитория команды и не устанавливает окончательные юридические метки. Нового просмотра видео при сборке нет.

## Проверка и пересборка без видео

Из корня репозитория; достаточно Python 3.12+ и стандартной библиотеки для этих трёх команд:

```sh
python reference/normative_coverage/reference_workflows/build_reference.py
python reference/normative_coverage/build_coverage.py
python reference/normative_coverage/reference_workflows/verify_reference.py
```

Если изменены сами темы общего каталога, сначала запустить `build_coverage.py`, затем три команды выше, чтобы сводка и процедуры были согласованы. Проверка сверяет идентификаторы, исходные ограничения, полные цитаты, SHA-256 оригиналов, графы порядка и локальные ссылки. Результат не устанавливает факты поведения на видео или юридическую применимость на неизвестную дату съёмки.

Для повторного извлечения HTML требуется `lxml`, для PDF — `pypdf`, для рендера проверяемых PDF-страниц — `pypdfium2`. Зафиксированные версии среды сборки перечислены в [requirements-research.txt](requirements-research.txt); они не добавлены в зависимости рабочего CVAT-сервиса.

Сетевые загрузчики `collect_sources.py`, `forte_public/collect_forte_public.py`, `forte_public/expand_forte_public.py` и `comparative_security/collect.py` обращаются только к публичным источникам. Для обычной проверки сохранённого пакета сеть не требуется.

## Локальная таблица сопоставления с видео

По умолчанию таблица и её показатели пересобираются из сохранённого `video_coverage.json` без чтения видео. При необходимости обновить предварительные исходные наблюдения можно явно указать собственные локальные входы `dataset_manifest.json` и `review_observations.py`:

```sh
python reference/normative_coverage/build_coverage.py --private-input-root /path/to/local/forte_analysis
```

Этот режим использует уже записанные предварительные описания, не выполняет новый анализ видео и не превращает исходные метки в доказанные нарушения. Сами локальные входы исключены из git. Отчёты `video_coverage.*` сохраняются в этом приватном репозитории команды; их нельзя выдавать за подтверждённую разметку или публиковать за пределами согласованного доступа к данным хакатона.

## Подключение к существующей системе

Основной вход — `reference_workflows/workflows.json`: `topic_procedures`, `references`, `observation_statuses`, `expected_record_fields`. Машинные идентификаторы тем и пунктов сохранены. Этот пакет не изменяет существующие сценарии и пороги в `reference/scenarios.yaml`; их согласование с нормативной моделью выполняется отдельно, с проверкой применимости и исключений.
