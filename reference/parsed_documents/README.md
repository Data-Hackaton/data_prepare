## Форматы

- `V….json` — все блоки, таблицы с rowspan и colspan, ссылки, примечания, заголовки и нумерованные фрагменты.
- `V….txt` — полный очищенный текст.
- `V….md` — читаемая версия с таблицами; точное объединение ячеек хранится в JSON и исходном HTML.
- `numbered_fragments.json` — общий индекс нумерованных фрагментов, включая постановления, цитируемые изменения и приложения.
- `manifest.json` — состав, SHA256 исходников и результаты проверки полноты.

Документ №49 получен через публичный API нового официального сайта «Әділет». Полный ответ сохранён в `V1900018545.api-metadata.json`, исходный HTML из поля `text_content` — в `V1900018545.source.html` без изменений. API помечает запись как актуальную (`is_actual: true`). Для остальных документов использованы ранее сохранённые официальные HTML в `../sources`.

Нумерованный фрагмент не равен самостоятельному действующему правилу. В постановлениях о поправках встречаются цитируемые редакции и повторная нумерация. Графические элементы, если они есть, сохраняются ссылками на оригиналы, без автоматической трактовки содержимого.
