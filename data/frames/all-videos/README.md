# Все видео для CVAT

42 ролика, 40 уникальных источников. Все уже извлечённые кадры по всей длительности (~1 кадр/с + последний кадр), без изменения разрешения 464×848. Это не все кадры видео 30 fps.

- `images/`, `manifest.csv` — формат data_prepare/cvat-io.
- `labels.json` — 13 классов из репозитория.
- `provenance.json` — исходные кадры, точные PTS там, где они известны, контрольные суммы.
- `preparation.json` — покрытие всех видео, дубликаты и train/val.

X-47 — копия X-4, X-48 — копия X-5; кадры обоих имен включены, каждая пара остаётся в одном split. Для обучения дубликаты следует исключить. Val: X-19, X-27, X-37, X-45 согласно исходному репозиторию.

Подготовка кадров сама по себе не является разметкой. Статус разметки хранится отдельно.
