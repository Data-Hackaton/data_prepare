# Дополнительный поиск внутренних правил ForteBank по Х-28

Дата проверки: **17.10.2026**. Искомое основание: обязанность работника кассы блокировать рабочий сеанс до любого краткого ухода. Такой общий внутренний документ с подтверждённой областью применения в этом поиске не найден. Это не утверждение, что правила не существует.

После расширения поиска на США и Европу собран [отдельный пакет сравнительных оснований](../../comparative_security/README.md): FDIC, NIST, ENISA/NCSA, PCI SSC, CNIL и исторический пример Банка Англии. Он позволяет обосновать риск открытого сеанса, но не закрывает пробел в доказательстве обязанности кассира ForteBank.

Семь публичных адресов проверены скриптом [fetch_public_indexes.py](fetch_public_indexes.py); успешные ответы, исходные URL, время и SHA-256 сохранены в `discovery/`. Поиск также охватывал прежнее название Alliance Bank. Результаты, где банк присутствует только в реквизитах сторонней организации, исключены.

## Что остаётся получить для утверждения о нарушении

1. Полный текст действовавших правил ИБ/использования рабочих станций и соответствующей инструкции кассира: ручная блокировка, адресат и исключения.
2. Дату события и идентификацию системы: клиентские правила ForteBusiness нельзя автоматически переносить на внутреннее кассовое ПО.
3. Подтверждение доступности сеанса без повторной аутентификации. Работающий экран не равен незаблокированному сеансу.

В исходном задании кейса полный внутренний регламент не предоставлен, предусмотрено исследование открытых источников. В рамках этого поиска контакты с банком или организаторами не выполнялись; видео заново не анализировались.
