# Все 42 видео: покадровая разметка CVAT

Результат обработки 17 октября 2026 года: 42 видео, 43 230 исходных кадров, шаг 1, 2 295 треков. Все исходные кадры декодированы; API CVAT и выгруженный XML проверены на явную разметку каждого кадра. Пропущенных или удалённых кадров нет.

Это **ассистированная разметка, требующая визуальной проверки**. Люди и кисти сопровождались автоматически, предметы и состояния уточнялись на просмотренных ключевых кадрах. Каждый исходный кадр не проверялся вручную. Покрытие кадров не подтверждает обнаружение всех объектов или точность каждой рамки; задания не отмечены как завершённая ручная валидация.

## Промежуточные исправления 18.10.2026

## Импорт в CVAT

1. Создать задачу из соответствующего `data/videos/X-n.mov` с шагом кадров 1 и схемой из `reports/labels-annotation.json` (имена, атрибуты и значения; серверные ID относятся к исходному запуску).
2. В задаче выбрать Upload annotations → **CVAT 1.1** и файл `per-video/X-n.zip`.
3. Для дальнейшей проверки использовать исходное видео с тем же SHA-256 и нумерацией кадров.

Общий проектный XML использует штатную глобальную нумерацию CVAT внутри subset. В отдельных архивах она приведена к локальной нумерации каждого видео. Архивы содержат аннотации; видео хранятся отдельно в `data/videos/`. Это экспорт аннотаций, а не резервная копия сервера CVAT.

## Что сделано

- Поднят локальный CVAT 2.79.0, создан проект и 42 задачи из полных видео.
- Проверены SHA-256, реальное количество и timestamps всех кадров; размер каждого кадра 464×848.
- Grounding DINO в проверенном FP32-режиме уточняет людей каждые 15 кадров, кисти каждые 10; между уточнениями рассчитывается оптический поток на каждом кадре.
- Предметы, банкноты, сумки, двери, сейфы и экраны дополнены по просмотренным изображениям. Между ключевыми кадрами используется интерполяция; неопределённые состояния отмечены `unknown`.
- Отражения отделены от людей в комнате; исправлены подтверждённые дубли рамок. Неоднозначные случаи сохранены для проверки, ограничения записаны в `quality` и `unresolved`.
- Импорт проверен обратным чтением из CVAT; существовавшие пользовательские объекты сохранены. Итоговая проверка: 42 задачи, 43 230 кадров с явными аннотациями, ошибок покрытия нет.

Роли людей опциональны и могут оставаться `unknown`. Геометрия мелких объектов, перекрытия руками, моменты появления/исчезновения и оставшиеся неоднозначные детекции требуют визуальной валидации. Precision/recall не измерялись; этот выпуск не следует выдавать за полностью проверенный ground truth.
