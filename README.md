# data_prepare

Подготовка датасета Datathon 26 и всё, что связано с CVAT. Видео и разметка в git не попадают; общий каталог данных — `../data` рядом с репозиториями.

## prepare

```sh
uv sync
uv run prepare /path/to/open.zip --out ../data
```

Результат:
- `data/videos/X-<n>.mov` — имена приведены к ASCII: в исходнике X-1 и X-2 с латинской X, остальные с кириллической Х.
- `data/labels.csv`: `video, n, source_name, verdict, timecode_sec, sha256, duplicate_of, duration_sec, fps, width, height`.

Что в данных на 17.10:
- 42 видео, уникальных 40: 21 с нарушением, 19 без. Пропущены номера 6, 7, 9, 36, 41, 42.
- X-47 побайтно совпадает с X-4, но таймкод нарушения 68 с против 57 с — вопрос организаторам. X-48 = X-5, оба без нарушения.
- Все видео 464×848, 30 fps, 11–143 с.
- При разбиении на train/val дубли держать в одной части.

## Дальше

- `contact_sheets` — раскадровки ±3 с вокруг размеченной секунды для каталога типов нарушений.
- `split` — train/val по уникальным видео.
- CVAT (поднимается по `infra/README.md`):
  - `labels.json` — схема меток: `person` (атрибут `role`), `cash`, `bag`, `drawer` / `safe` (атрибут `state`), `phone`, `event` (прямоугольный трек на время действия, атрибут `type`);
  - `cvat_upload` — задачи на 40 уникальных видео, frame step 5;
  - `pull_annotations` — CVAT → эталон для eval;
  - `push_predictions` — предсказания → задача `<video>-pred` для разбора ошибок.
- `augment` — отражение, поворот, перспектива, кроп: проверка устойчивости к другому ракурсу.
